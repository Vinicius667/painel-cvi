# Tela de TV — Viagens CVI

Retrato estático da Tela de TV das viagens institucionais da Coordenação de Viagens Institucionais (CVI) da AgSUS.

- Tela: `index.html` (abre direto do disco ou em qualquer hospedagem estática, como o GitHub Pages)
- Dados: `dados/` — só o que a tela mostra (totais, meses, os 6 que mais viajaram e os 6 maiores destinos, regiões e rotas)

Gerado pelo repositório `monitoramento_CVI` com `npm run build:tv` (em `dashboard/`).
